# Demo

Sample output, generated by running the real code path — `src/cli.ts` →
`src/fetchers/` → `src/cards/` — against a stubbed GitHub API. The data is
made up; the rendering is not.

Regenerate them with the action itself, or locally:

```bash
PAT_1=your_token \
GH_CARD_CARD=user \
GH_CARD_PARAMS="username=octocat&show_icons=true" \
GH_CARD_PATH=demo/user.svg \
node src/cli.ts
```

| File                | What it is                                              |
| ------------------- | ------------------------------------------------------- |
| `user.svg`          | The stats card, straight from the renderer               |
| `repo.svg`          | The repository card                                      |
| `langs.svg`         | The languages card, `compact` layout                     |
| `*.png`             | 2× previews of the above, for the readme                 |
| `user-radical.png`  | Stats card in the `radical` theme                        |
| `langs-donut.png`   | Languages card in the `donut` layout, `radical` theme    |

The SVGs are the real artefacts and are what a profile repository would commit.
The PNGs are previews: they were rasterised with Inter substituted for
`Segoe UI`, and with the entrance animations forced to their end state, because
the rasteriser available here has neither the font nor a CSS animation engine.
In a browser the SVGs animate as intended.
